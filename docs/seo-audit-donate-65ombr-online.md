## Підсумок

Сторінка доступна через HTTPS, повертає `200 OK`, дозволена для індексації, містить один H1, коректний `lang="uk"`, синхронізований FAQ JSON-LD і робочі локальні посилання. Основні проблеми — відсутність canonical, sitemap і robots, доступність дубля `/index.html`, слабкий H1 для цільового запиту та перевантажені title/meta. Публічний пошук не показав результатів за доменом; це не доводить відсутності в індексі, остаточна перевірка можлива лише через Google Search Console.

## Критичні виправлення

### 1. Задати основний URL

- **Поточний стан:** `/` та `/index.html` повертають однакову сторінку з `200 OK`; canonical відсутній.
- **Проблема:** пошуковій системі доводиться самостійно вибирати основний URL; внутрішні посилання з donation/thanks посилюють дубль `/index.html`.
- **Виправлення:** додати на головну `<link rel="canonical" href="https://donate.65ombr.online/">`, `og:url` із тим самим URL і замінити посилання `index.html` / `index.html#selector` на `/` / `/#selector`.

### 2. Налаштувати виявлення та контроль індексації

- **Поточний стан:** `/robots.txt` і `/sitemap.xml` повертають 404; публічний пошук не показав результатів за доменом.
- **Проблема:** це не блокує Googlebot, але для нового односторінкового сайту без підтверджених зовнішніх посилань уповільнює виявлення та позбавляє власника діагностики.
- **Виправлення:** створити sitemap лише з `https://donate.65ombr.online/`, додати robots із дозволом обходу та посиланням на sitemap; підтвердити право власності на домен у Google Search Console, надіслати sitemap і запросити індексацію головної через URL Inspection.

### 3. Опублікувати актуальну версію

- **Поточний стан:** опублікована сторінка має `Last-Modified: 2026-11-08`; PR #6 відкритий і не злитий.
- **Проблема:** пошукові системи бачать старий текст без останніх правок SKORN.
- **Виправлення:** після затвердження SEO-змін злити PR, дочекатися успішного розгортання GitHub Pages і повторно перевірити опублікований HTML.

## Важливі виправлення

### 1. Поліпшити title, description і H1

- Скоротити title до безпечної довжини.
- Переписати description без суми та Zaslip, якщо ці деталі не мають з’являтися в пошуковому сніпеті.
- Зробити H1 описовим для запитів «допомога ЗСУ» та «65 ОМБр», а «З нас — дрон. З вас — зв’язок» залишити візуальним слоганом.

### 2. Додати повноцінну картку для соцмереж

- Додати абсолютні `og:image`, `twitter:image`, `og:image:width`, `og:image:height`, `og:image:alt`.
- Використати зображення 1200×630 і `twitter:card=summary_large_image`.

### 3. Оптимізувати перший екран

- `skorn-pixel.png` — 1,39 МБ, `brigade_logo-site-style.png` — 1,38 МБ; обидва 1254×1254, хоча відображаються приблизно у 200–270 px.
- Підготувати версії близько 512×512 в оптимізованому PNG/WebP зі збереженням чіткості піксель-арту.
- Залишити зображення першого екрана без відкладеного завантаження; динамічні картки деталей уже використовують `loading="lazy"`.

### 4. Виправити помилки HTML-валідатора

- W3C Nu на опублікованому сайті знайшов `aria-label` на звичайному `div` без відповідної ролі та неприпустимий `role="img"` на `section`.
- Це не блокує індексацію безпосередньо, але впливає на якість розмітки та доступність.

## Додаткові поліпшення

- Додати `WebSite` JSON-LD із назвою, URL та `inLanguage`; FAQPage можна залишити, але Google зазвичай не показує розширені результати FAQ для сайтів поза авторитетними державними та медичними ресурсами.
- Отримати хоча б одне індексоване зовнішнє посилання з офіційного ресурсу бригади або публічної сторінки збору.
- Виключити `assets/source/` і невикористовувані проміжні файли з артефакту Pages.
- Підключити Bing Webmaster Tools після налаштування sitemap.
- Перевірити Core Web Vitals після публікації через Search Console/PageSpeed. Автоматичний PageSpeed API під час аудиту повернув 429, тому лабораторні показники не підтверджено.

## Примітки щодо реалізації

`robots.txt`:

```text
User-agent: *
Allow: /
Sitemap: https://donate.65ombr.online/sitemap.xml
```

До sitemap включати лише індексовану головну сторінку. `donation.html` і `thanks.html` правильно мають `noindex,follow` і не повинні потрапляти до sitemap.

## Перевірити після розгортання

- [ ] `/`, canonical, `og:url` і sitemap використовують один URL.
- [ ] `/robots.txt` і `/sitemap.xml` повертають 200.
- [ ] donation/thanks посилаються на `/`, а не `/index.html`.
- [ ] Search Console Live Test бачить H1, текст, CSS, JS і зображення.
- [ ] URL Inspection показує головну як доступну для індексації.
- [ ] Rich Results Test приймає JSON-LD без помилок.
- [ ] Зображення Open Graph відображається в попередньому перегляді Telegram/Facebook.
- [ ] Core Web Vitals перевірено після накопичення даних.
