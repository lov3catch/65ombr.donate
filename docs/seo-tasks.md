# SEO-задачи для donate.65ombr.online

Дата составления: 2026-11-18  
Основание: `seo-audit-donate-65ombr-online.md`

Статус: локальная реализация выполнена и отправлена в PR #6; публикация, Search Console и внешние действия ожидают слияния и доступа.

## Целевые поисковые запросы

- **Основной:** `допомога ЗСУ`
- **Транзакционный:** `задонатити на ЗСУ`
- **Брендовый:** `65 ОМБр`
- **Тематический:** `модернізація важкого дрона`

В пользовательском тексте использовать правильное написание `65 ОМБр` с пробелом. Вариант `65омбр` не нужно искусственно повторять: поисковые системы обычно понимают его как тот же запрос.

Распределение запросов:

- title и H1 — `допомога ЗСУ` + `65 ОМБр`;
- meta description — все три основных запроса;
- первый абзац — естественная фраза о помощи ЗСУ и получателе;
- FAQ или заголовок перед выбором деталей — `Як задонатити на ЗСУ`;
- описание цели — просто `модернізація важкого дрона`, без дополнительного технического уточнения.

## Приоритет 1 — индексация и основной URL

- [x] Добавить на главную страницу canonical:

  ```html
  <link rel="canonical" href="https://donate.65ombr.online/" />
  ```

  **Файл:** `deploy/index.html`  
  **Готово, когда:** в исходном коде опубликованной страницы присутствует один абсолютный canonical на корневой URL.

- [x] Добавить абсолютный `og:url`:

  ```html
  <meta property="og:url" content="https://donate.65ombr.online/" />
  ```

  **Файл:** `deploy/index.html`  
  **Готово, когда:** `og:url` совпадает с canonical.

- [x] Заменить внутренние ссылки на `index.html`:

  - `index.html` → `/`
  - `index.html#selector` → `/#selector`

  **Файлы:** `deploy/donation.html`, `deploy/thanks.html`  
  **Готово, когда:** внутренние страницы больше не усиливают дубль `/index.html`.

- [x] Создать `robots.txt`:

  ```text
  User-agent: *
  Allow: /
  Sitemap: https://donate.65ombr.online/sitemap.xml
  ```

  **Файл:** `deploy/robots.txt`  
  **Готово, когда:** `https://donate.65ombr.online/robots.txt` возвращает `200 OK`.

- [x] Создать sitemap только с индексируемой главной страницей.

  **Файл:** `deploy/sitemap.xml`  
  **Включить:** `https://donate.65ombr.online/`  
  **Не включать:** `donation.html`, `thanks.html`, `/index.html`  
  **Готово, когда:** sitemap валиден и возвращает `200 OK`.
