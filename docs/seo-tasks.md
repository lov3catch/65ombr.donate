# SEO-завдання для donate.65ombr.online

Дата складання: 2026-11-18  
Підстава: `seo-audit-donate-65ombr-online.md`

> Статуси наведено на дату складання: локальну реалізацію виконано й надіслано в PR #6; публікація, Search Console та зовнішні дії очікують злиття й доступу. Стан опублікованого сайту та PR потребує повторної перевірки. Шляхи нижче наведено від кореня репозиторію (`deploy/` у робочій папці).

## Цільові пошукові запити

- **Основний:** `допомога ЗСУ`
- **Транзакційний:** `задонатити на ЗСУ`
- **Брендовий:** `65 ОМБр`
- **Тематичний:** `модернізація важкого дрона`

У тексті для користувачів використовувати правильне написання `65 ОМБр` із пробілом. Варіант `65омбр` не потрібно штучно повторювати: пошукові системи зазвичай розуміють його як той самий запит.

Розподіл запитів:

- title і H1 — `допомога ЗСУ` + `65 ОМБр`;
- meta description — усі три основні запити;
- перший абзац — природна фраза про допомогу ЗСУ та отримувача;
- FAQ або заголовок перед вибором деталей — `Як задонатити на ЗСУ`;
- опис мети — просто `модернізація важкого дрона`, без додаткового технічного уточнення.

## Пріоритет 1 — індексація та основний URL

- [x] Додати на головну сторінку canonical:

  ```html
  <link rel="canonical" href="https://donate.65ombr.online/" />
  ```

  **Файл:** `index.html`  
  **Готово, коли:** у вихідному коді опублікованої сторінки є один абсолютний canonical на кореневий URL.

- [x] Додати абсолютний `og:url`:

  ```html
  <meta property="og:url" content="https://donate.65ombr.online/" />
  ```

  **Файл:** `index.html`  
  **Готово, коли:** `og:url` збігається з canonical.

- [x] Замінити внутрішні посилання на `index.html`:

  - `index.html` → `/`
  - `index.html#selector` → `/#selector`

  **Файли:** `donation.html`, `thanks.html`  
  **Готово, коли:** внутрішні сторінки більше не посилюють дубль `/index.html`.

- [x] Створити `robots.txt`:

  ```text
  User-agent: *
  Allow: /
  Sitemap: https://donate.65ombr.online/sitemap.xml
  ```

  **Файл:** `robots.txt`  
  **Готово, коли:** `https://donate.65ombr.online/robots.txt` повертає `200 OK`.

- [x] Створити sitemap лише з індексованою головною сторінкою.

  **Файл:** `sitemap.xml`  
  **Включити:** `https://donate.65ombr.online/`  
  **Не включати:** `donation.html`, `thanks.html`, `/index.html`  
  **Готово, коли:** sitemap валідний і повертає `200 OK`.

## Пріоритет 2 — пошуковий сніпет і заголовки

- [x] Скоротити title.

  **Запропонований варіант:**

  ```text
  Допомога ЗСУ — збір для 65 ОМБр | Важлива деталь
  ```

  **Файл:** `index.html`  
  **Готово, коли:** title унікальний, відповідає сторінці та не перевищує приблизно 60 символів.

- [x] Переписати meta description без суми та згадки Zaslip.

  **Запропонований варіант:**

  ```text
  Допомога ЗСУ для підрозділу SKORN 65 ОМБр: збір на модернізацію важкого дрона. Оберіть необхідну деталь, щоб задонатити на ЗСУ через monobank.
  ```

  **Файл:** `index.html`  
  **Готово, коли:** description відображає фактичний зміст, містить ненав’язливий заклик до дії та не обрізається в типовому сніпеті.

- [x] Синхронізувати `og:title`, `og:description`, `twitter:title` і `twitter:description` із новим позиціюванням.

  **Файл:** `index.html`  
  **Готово, коли:** пошуковий і соціальний описи не суперечать видимому тексту сторінки.

- [x] Зробити H1 описовим.

  **Запропонований H1:**

  ```text
  Допомога ЗСУ: збір для підрозділу SKORN 65 ОМБр
  ```

  Слоган `З нас — дрон. З вас — зв’язок` залишити окремим візуальним текстом поруч із H1.

  **Файли:** `index.html`, за потреби `styles.css`  
  **Готово, коли:** на сторінці залишається рівно один H1 із фразами `допомога ЗСУ` та `65 ОМБр`.

- [x] Додати цільові запити у видимий текст без надмірного повторення.

  **Перший абзац:** природно зазначити, що це благодійний збір на допомогу ЗСУ для підрозділу SKORN 65 ОМБр.  
  **FAQ або заголовок:** використати формулювання `Як задонатити на ЗСУ`.  
  **Опис мети:** писати просто `модернізація важкого дрона`, без додаткового технічного уточнення.  
  **Готово, коли:** кожна цільова фраза стоїть у логічному місці, а текст читається природно й не схожий на набір ключових слів.

## Пріоритет 3 — попередній перегляд у соцмережах

- [x] Підготувати зображення кампанії розміром 1200×630.

  **Файл:** `assets/campaign-social-card.jpg`  
  **Готово, коли:** зображення читається в малому попередньому перегляді та не містить дрібного тексту.

- [x] Додати метадані зображення Open Graph і Twitter:

  - `og:image`
  - `og:image:width`
  - `og:image:height`
  - `og:image:alt`
  - `twitter:image`
  - `twitter:card=summary_large_image`

  **Файл:** `index.html`  
  **Готово, коли:** усі URL абсолютні, а картка коректно відображається в попередньому перегляді Telegram/Facebook.

## Пріоритет 4 — продуктивність

- [ ] Оптимізувати два логотипи першого екрана:

  - `assets/skorn-pixel.png`
  - `assets/brigade_logo-site-style.png`

  Файли на дату складання мали розмір 1254×1254 і важили приблизно по 1,3–1,4 МБ. Підготувати версії близько 512×512 в оптимізованому PNG або WebP зі збереженням чіткості піксель-арту.

  **Готово, коли:** візуальну якість збережено, прозорість працює, загальний розмір суттєво зменшено.

- [ ] Після публікації перевірити продуктивність мобільної та настільної версій.

  **Перевірити:** LCP, CLS, INP, обсяг переданих даних, завантаження першого екрана.  
  **Інструменти:** PageSpeed Insights і Core Web Vitals у Search Console.

## Пріоритет 5 — якість HTML і доступність

- [x] Виправити `aria-label` на звичайному `div` без відповідної ролі.

  **Файл:** `index.html`  
  **Готово, коли:** W3C Nu більше не повертає цю помилку.

- [x] Замінити неприпустимий `role="img"` на елементі `section` коректною семантикою.

  **Файл:** `index.html`  
  **Готово, коли:** зміст декоративної сцени залишається доступним для читача з екрана, а валідатор не повідомляє про помилку.

- [x] Повторно перевірити HTML через W3C Nu Validator.

  **Готово, коли:** немає помилок рівня `error`; інформаційні повідомлення про закривальну скісну риску в стилі XHTML можна залишити.

## Остаточна перевірка після розгортання

- [ ] `https://donate.65ombr.online/` повертає `200 OK`.
- [ ] HTTP і старий URL GitHub Pages перенаправляють на основний HTTPS-домен.
- [ ] Canonical, `og:url` і sitemap указують на один URL.
- [ ] `robots.txt` і `sitemap.xml` повертають `200 OK`.
- [ ] На головній рівно один H1.
- [ ] `donation.html` і `thanks.html` зберігають `noindex,follow`.
- [ ] JSON-LD валідний і відповідає видимому FAQ.
- [ ] Внутрішні посилання та ресурси не повертають 404.
- [ ] Картка посилання відображається із зображенням у соцмережах.
