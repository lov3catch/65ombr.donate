# Практики для нових макетів «Важлива деталь»

Відкрийте [index.html](index.html) у браузері. Приклади працюють офлайн і показують кольори, стани компонентів, чотири формати банера, масштабування спрайтів і коротку анімацію.

## Як застосовувати приклади

| Завдання | Робіть так | Перевірте перед передачею |
|---|---|---|
| Новий блок сайту | Використайте одну головну дію з бурштиновою заливкою та темним текстом. Укладіть другорядні дії в контурні кнопки | Ширини 320, 375, 720, 960 і 1440 px. Помітний фокус із клавіатури й зона натискання від 44 px для нових кнопок |
| Стани вибору | Покажіть галочку, контур і числовий підпис. Для приглушення зменшуйте насиченість ілюстрації | Назва читається в обох станах. Картку можна вибрати, зняти вибір і дістатися до неї з клавіатури |
| Масштаб типографіки | Заголовок — Arial Black або Impact. Пояснення — Segoe UI. Цифри й мітки — Cascadia Mono або системна підстановка | Українські символи, перенос довгої фрази, контраст поверх фактичного фону. Для нового звичайного тексту закладайте щонайменше 4,5:1 |
| Обкладинка | Виберіть один головний силует і 1–2 рядки заголовка. У широкому форматі почніть з зон 45:55. Вертикаль зберіть окремо | Читабельність у мініатюрі та кадрування в місці публікації. Пунктир в HTML показує стартові поля композиції |
| Предмет або персонаж | Почніть з контуру, додайте великі плями світла й тіні. Масштабуйте кратно, зі збереженням піксельних країв | Силует читається в натуральному розмірі. У серії кадрів однакові полотно, базова лінія та напрям світла |
| Анімація | Задайте тривалість, ключові пози, паузу і фінальний кадр. В інтерактивному прикладі рух є локальним і запускається вручну | Перевірте відтворення, паузу, повернення до статичного кадру та системне налаштування зменшеного руху |

## Які полотна підготувати

| Формат | Розмір | Стартові поля |
|---|---:|---|
| Прев’ю посилання | 1200×630 | 60 px по периметру |
| Широкий банер | 2172×724 | 5% відповідної сторони з кожного краю |
| Квадратна картка | 1080×1080 | 72 px по периметру |
| Вертикальна історія | 1080×1920 | 80 px з боків, 240 px зверху та знизу |

## Що передати

- Редагований майстер із шарами тла, тексту, ілюстрації та емблем.
- Фінальні файли відповідних розмірів. Прозорі спрайти у PNG, непрозоре фото зазвичай у JPEG або WebP, анімація для сайту залежно від задачі у CSS, sprite sheet або MP4.
- Для нової анімації — тривалість, режим повтору, спосіб паузи й статичний кадр. Для змістовної ілюстрації — короткий опис.
- У цьому наборі використано чинні спрайти проєкту: `part-01-raspberry-pi4.png`, `part-05-fan-60x60.png`, `sprites/halloween-pine-tree.png` та `sprites/halloween-zombie.png`. Їхні копії вбудовано в HTML для офлайн-перегляду.
